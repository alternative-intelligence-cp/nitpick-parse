## 7. What will bite

- **The sweep reads what git tracks**: a `.npk` written and not added is not swept. `apply.py` stages what it writes
  (`git apply --index`), so every step's files are swept by its own block; a file made by hand is `git add`ed first.
- **An index through a pointer does not trap**: a container's check is its only bound, and a mutant that removes one is
  red only where a unit reads past the count.

- **A `buffer` could not be ranged at `7e91730`**, so nothing returns a view of `Bytes`, and a copy is the only way
  out: from the compiler's landing 128 (D-341), in the pin, its range is a frozen view (§1.10), which no decision has
