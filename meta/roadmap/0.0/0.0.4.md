## 7. What will bite

- **An index through a pointer does not trap**: a container's check is its only bound, and a mutant that removes one is
  red only where a unit reads past the count.
- **A `Vec` is an owner** (a block the scope must free): a unit that forgets `vec_free` exits `WildLeak`, 96.
- **A `buffer` could not be ranged at `7e91730`**, so nothing returns a view of `Bytes`, and a copy is the only way
  out: from the compiler's landing 128 (D-341), in the pin, its range is a frozen view, which no decision has taken.
